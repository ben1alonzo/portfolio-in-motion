# portfolio-in-motion

An expansion of my resume, designed to go further into my professional path and life experiences.

## Vision

A minimalist portfolio with a realistic 3D business card floating **dead center, level, and front-facing** in a fixed scene. The card remains motionless until the visitor drags it horizontally to rotate it around its vertical axis, revealing the back. A stationary light source creates subtle changing highlights. In a later phase, the lower front face becomes the site's navigation bar.

## Development

This project is built openly, one working increment at a time.

- [Architecture and interaction principles](docs/ARCHITECTURE.md)
- [Milestone roadmap and contribution workflow](docs/ROADMAP.md)

**Planned stack:** Next.js (App Router), TypeScript, React Three Fiber, Drei, and Three.js.

**Release plan:** v0.1 foundation → v0.2 geometry → v0.3 lighting → v0.4 horizontal dragging → v0.5 polish (Phase 1) → v0.6 navigation → v1.0 portfolio launch.

Each feature should have its own branch and pull request. Milestone releases will include screenshots or GIFs and concise implementation notes.
